Medio 🎧
Your files. A proper listening experience.

Medio is a versatile iPhone media player designed for personal media libraries, stripping away streaming bloat to focus entirely on your audio files. Built with a focused interface and a seamless workflow, it gives you complete control over your listening environment.

✨ Key Features
Local Library Focus: A dedicated environment built exclusively for personal media, lossless rips, and custom audio files.

Optional Online Features: Supports network and cloud features for flexibility, but every online capability can be completely turned off in settings for a fully offline-first experience.

Distraction-Free Interface: A pristine UI that puts album artwork and playback controls front and center.

Optimized Workflow: Engineered to make managing, searching, and listening to your media fast and effortless.

🛠 Tech Stack & Requirements
Platform: iOS 15.5+

Frameworks: SwiftUI, AVFoundation

IDE: Xcode
