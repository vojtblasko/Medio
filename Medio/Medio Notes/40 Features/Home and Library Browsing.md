# Home and Library Browsing

Home and Library are the main surfaces for moving through local files and derived music collections.

## User Jobs

- Open recent and priority folders.
- Browse files in icons, list, or desktop-style layouts.
- Inspect folders, albums, artists, and file details.
- Start playback from the current context.
- Move files and create folders while staying inside the Documents boundary.

## Data Inputs

- [[Library Indexing]] supplies files, songs, albums, and artists.
- [[Metadata and Artwork]] supplies display names, imagery, colors, and visual overrides.
- [[State Stores]] supply browsing preferences and observable collection state.
- [[Persistence]] supplies favorites and last-opened records.

## UI Surfaces

- `HomeScreen`
- `LibraryScreen`
- `FolderPanel`
- `AlbumPanel`
- `ArtistPanel`
- `FileAboutPanel`
- `FolderBrowserScreen`
- desktop/grid drag-and-drop bridges
